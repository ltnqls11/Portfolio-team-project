# 구현 계획 (MVP 중심)

## 성공 지표 (Success Metrics)
- **비즈니스**: 3개월 내 유료 사용자 50명 확보
- **성능**: 캠페인 생성부터 문구 저장까지 5분 이내 완료
- **만족도**: 사용자 만족도 설문조사 점수 4.0/5.0 이상 달성

## 서비스 이용 단계
1. 사용자 로그인
2. '새 캠페인 만들기' 버튼 클릭
3. 캠페인 정보, 제품 정보 등 필수 정보 입력
4. AI가 각 채널에 맞는 문구 생성 및 사용자 선택, 저장
5. 인플루언서 목록에서 적합한 대상 선택
6. 선택된 인플루언서에게 연락 발송 (초기에는 수동)
7. 발송 상태 추적 및 결과 확인
