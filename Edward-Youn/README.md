# 온라인 마케팅 연계 플랫폼

## 📌 플랫폼 소개
기업이 자신의 제품 또는 서비스를 홍보할 수 있도록 최적화된 올인원 마케팅 자동화 플랫폼입니다.

### 🎯 한 줄 정의
**"기업이 네이버 블로거를 발굴하고 선택해서, 맞춤형 포스팅 제안 메일을 발송하는 마케팅 연계 플랫폼"**

### 💡 핵심 가치
1. **블로거 자동 발굴**: 네이버 블로그를 자동 크롤링하여 카테고리별 블로거 데이터베이스 구축
2. **기업 주도 선택**: 기업이 직접 적합한 블로거를 선택하고 포스팅 제안 메일 발송
3. **문구 자동화**: 제품/서비스에 맞는 포스팅 제안 문구를 자동 생성

## 🚀 주요 기능

### 1. 네이버 블로거 자동 발굴
- 키워드 기반 네이버 블로그 자동 크롤링
- 카테고리별 블로거 분류 (뷰티, 패션, 음식, 여행 등)
- 블로거 정보 수집 (포스팅 수, 활동성, 연락처 등)
- 블로거 데이터베이스 구축 및 관리

### 2. 기업 주도 블로거 선택 시스템
- 카테고리별 블로거 목록 조회
- 블로거 상세 정보 확인 (블로그 분석, 포스팅 스타일 등)
- 기업이 직접 적합한 블로거 선택
- 선택된 블로거에게 포스팅 제안 메일 발송

### 3. 포스팅 제안 문구 자동 생성
- 제품/서비스 정보 기반 맞춤형 제안 문구 생성
- 네이버 블로그 최적화된 포스팅 가이드라인 제공
- 협찬 조건 및 요구사항 자동 포함
- 메일 템플릿 자동 생성

## 🛠️ 기술 스택

### Backend
- **Framework**: FastAPI
- **Database**: PostgreSQL
- **ORM**: SQLAlchemy / SQLModel
- **크롤링**: BeautifulSoup4, Selenium, Apify

### Frontend
- **Framework**: React + Vite
- **UI Library**: shadcn/ui
- **차트**: Recharts, Plotly.js
- **상태관리**: Redux Toolkit / Zustand

### Automation
- **오케스트레이션**: N8N
- **스케줄링**: APScheduler, Celery
- **메일**: SMTP / SendGrid
- **크롤링 자동화**: Apify

## 📊 데이터베이스 스키마

- **creators**: 인플루언서 정보
- **outreach**: 연락 이력
- **deliverables**: 게시물 및 성과
- **events**: 이벤트 로그
