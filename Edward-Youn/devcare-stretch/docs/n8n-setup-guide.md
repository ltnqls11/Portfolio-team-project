# n8n 설치 및 설정 가이드\n\n## 🚀 n8n 빠른 시작\n\n### 1. 사전 요구사항\n- Docker 및 Docker Compose 설치\n- 모든 필요한 API 키 준비\n- DevCare Stretch 백엔드 서버 실행 중\n\n### 2. 환경 변수 설정\n```bash\n# n8n 환경 변수 파일 생성\ncp n8n.env.example .env\n\n# .env 파일을 편집하여 실제 API 키들 입력\nnano .env\n```\n\n### 3. n8n 실행\n```bash\n# n8n 컨테이너 시작\ndocker-compose -f docker-compose.n8n.yml up -d\n\n# 로그 확인\ndocker-compose -f docker-compose.n8n.yml logs -f n8n\n```\n\n### 4. n8n 접속\n1. 브라우저에서 `http://localhost:5678` 접속\n2. 기본 인증 정보로 로그인:\n   - Username: `admin`\n   - Password: `devcare2024!`\n\n## 📁 워크플로우 Import\n\n### 방법 1: 웹 인터페이스에서 Import\n1. n8n 웹 인터페이스 접속\n2. 좌측 메뉴에서 \"Workflows\" 클릭\n3. \"Import from file\" 버튼 클릭\n4. `n8n-workflows/` 폴더의 JSON 파일들을 하나씩 import\n\n### 방법 2: CLI를 통한 Import (고급)\n```bash\n# 컨테이너 내부로 접속\ndocker exec -it devcare-n8n bash\n\n# 워크플로우 import\nn8n import:workflow --input=/workflows/youtube-data-ingestion.json\nn8n import:workflow --input=/workflows/slack-notifications.json\n```\n\n## ⚙️ 워크플로우 설정\n\n### 1. YouTube 데이터 수집 워크플로우\n\n**설정해야 할 항목들:**\n1. **Cron Trigger**: 매일 새벽 6시 KST로 설정 확인\n2. **HTTP Request 노드들**: API 키 환경변수 연결 확인\n3. **Backend URL**: 환경변수에서 올바른 백엔드 URL 설정\n\n**활성화 방법:**\n1. \"YouTube Data Ingestion\" 워크플로우 열기\n2. 우측 상단 \"Active\" 토글 켜기\n3. \"Save\" 버튼 클릭\n\n### 2. Slack 알림 워크플로우\n\n**웹훅 URL 설정:**\n1. \"Slack Notifications\" 워크플로우 열기\n2. \"Webhook Trigger\" 노드 클릭\n3. 생성된 웹훅 URL 복사\n4. 백엔드 `.env` 파일에 추가:\n   ```\n   N8N_WEBHOOK_URL=http://localhost:5678/webhook/slack-schedule\n   ```\n\n**활성화 방법:**\n1. 워크플로우 우측 상단 \"Active\" 토글 켜기\n2. \"Save\" 버튼 클릭\n\n## 🔧 고급 설정\n\n### 환경별 설정\n\n**개발 환경:**\n```bash\n# 개발용 설정으로 실행\nBACKEND_URL=http://localhost:5000 docker-compose -f docker-compose.n8n.yml up -d\n```\n\n**프로덕션 환경:**\n```bash\n# 프로덕션 URL로 변경\nBACKEND_URL=https://your-production-api.com docker-compose -f docker-compose.n8n.yml up -d\n```\n\n### PostgreSQL 사용하기 (선택사항)\n\n기본적으로 SQLite를 사용하지만, 더 나은 성능을 위해 PostgreSQL을 사용할 수 있습니다:\n\n1. `docker-compose.n8n.yml`에서 PostgreSQL 관련 주석 해제\n2. n8n 서비스의 환경변수 변경:\n   ```yaml\n   - DB_TYPE=postgresdb\n   - DB_POSTGRESDB_HOST=n8n-postgres\n   - DB_POSTGRESDB_PORT=5432\n   - DB_POSTGRESDB_DATABASE=n8n\n   - DB_POSTGRESDB_USER=n8n\n   - DB_POSTGRESDB_PASSWORD=n8n_password\n   ```\n\n## 🐛 문제 해결\n\n### 일반적인 문제들\n\n**1. API 키 관련 오류**\n```bash\n# 환경변수 확인\ndocker exec devcare-n8n env | grep API\n\n# n8n 재시작\ndocker-compose -f docker-compose.n8n.yml restart n8n\n```\n\n**2. 웹훅 연결 실패**\n- 백엔드 서버가 실행 중인지 확인\n- 방화벽 설정 확인\n- Docker 네트워크 설정 확인\n\n**3. 워크플로우 실행 실패**\n```bash\n# 실행 로그 확인\ndocker-compose -f docker-compose.n8n.yml logs n8n\n\n# 컨테이너 상태 확인\ndocker ps\n```\n\n### 로그 모니터링\n```bash\n# 실시간 로그 확인\ndocker-compose -f docker-compose.n8n.yml logs -f\n\n# 특정 서비스만 로그 확인\ndocker-compose -f docker-compose.n8n.yml logs -f n8n\n```\n\n## 📊 모니터링 및 관리\n\n### 워크플로우 실행 상태 확인\n1. n8n 웹 인터페이스에서 \"Executions\" 메뉴 클릭\n2. 각 워크플로우의 실행 이력 및 성공/실패 상태 확인\n3. 실패한 실행의 경우 상세 로그 확인\n\n### 정기적인 유지보수\n```bash\n# 컨테이너 업데이트\ndocker-compose -f docker-compose.n8n.yml pull\ndocker-compose -f docker-compose.n8n.yml up -d\n\n# 사용하지 않는 데이터 정리\ndocker system prune -f\n```\n\n## 🔒 보안 고려사항\n\n1. **인증 정보 변경**: 기본 패스워드를 반드시 변경하세요\n2. **방화벽 설정**: 필요한 포트만 열어두세요\n3. **HTTPS 설정**: 프로덕션에서는 SSL 인증서 사용\n4. **API 키 보안**: .env 파일을 git에 커밋하지 마세요\n\n## 🌐 외부 접근 설정 (선택사항)\n\n외부에서 n8n에 접근하려면:\n\n1. **도메인 설정**:\n   ```yaml\n   environment:\n     - N8N_HOST=your-domain.com\n     - N8N_PROTOCOL=https\n     - WEBHOOK_URL=https://your-domain.com\n   ```\n\n2. **리버스 프록시 설정** (nginx 예시):\n   ```nginx\n   server {\n       listen 80;\n       server_name your-domain.com;\n       \n       location / {\n           proxy_pass http://localhost:5678;\n           proxy_set_header Host $host;\n           proxy_set_header X-Real-IP $remote_addr;\n       }\n   }\n   ```"
