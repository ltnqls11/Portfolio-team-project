[n8n.io](https://n8n.io) 접속\n2. \"Start for free\" 클릭\n3. 계정 생성 (GitHub/Google 연동 가능)\n4. 무료 플랜으로 시작 (월 5000회 실행 무료)\n\n### 2단계: 환경 변수 설정\n1. n8n 대시보드에서 **Settings** → **Environment variables** 클릭\n2. 다음 변수들을 추가:\n\n```env\n# YouTube Data API v3\nYOUTUBE_API_KEY=your_youtube_api_key_here\n\n# OpenAI API\nOPENAI_API_KEY=your_openai_api_key_here\n\n# Google Gemini API\nGEMINI_API_KEY=your_gemini_api_key_here\n\n# Slack API\nSLACK_BOT_TOKEN=xoxb-your-slack-bot-token\nSLACK_SIGNING_SECRET=your_slack_signing_secret\n\n# DevCare Stretch Backend\nBACKEND_URL=https://your-backend-url.com\n# 또는 로컬 테스트: http://your-public-ip:5000\n\n# Supabase\nSUPABASE_URL=https://your-project.supabase.co\nSUPABASE_SERVICE_KEY=your_supabase_service_key\n```\n\n### 3단계: 워크플로우 Import\n\n**방법 1: JSON 복사/붙여넣기 (권장)**\n\n1. n8n 대시보드에서 **+ Create** → **Import** 클릭\n2. \"Paste JSON\" 탭 선택\n\n**YouTube 데이터 수집 워크플로우:**\n```bash\n# n8n-workflows/youtube-data-ingestion.json 파일 내용을 복사해서 붙여넣기\n```\n\n**Slack 알림 워크플로우:**\n```bash\n# n8n-workflows/slack-notifications.json 파일 내용을 복사해서 붙여넣기\n```\n\n**방법 2: 파일 업로드**\n1. \"Upload file\" 탭 선택\n2. JSON 파일들을 직접 업로드\n\n### 4단계: 웹훅 URL 설정\n\n**Slack 워크플로우 웹훅 URL 확인:**\n1. \"DevCare Slack Notifications\" 워크플로우 열기\n2. \"Webhook Trigger\" 노드 클릭\n3. **Production URL** 복사 \n   - 예: `https://your-instance.app.n8n.cloud/webhook/slack-schedule`\n\n**백엔드에 웹훅 URL 설정:**\n```env\n# backend/.env 파일에 추가\nN8N_WEBHOOK_URL=https://your-instance.app.n8n.cloud/webhook/slack-schedule\n```\n\n### 5단계: 워크플로우 활성화\n1. 각 워크플로우를 열어서 **Active** 토글 켜기\n2. **Save** 버튼 클릭\n3. YouTube 워크플로우는 매일 새벽 6시에 자동 실행됩니다!\n\n## ✅ 완전 자동화 확인\n\n### YouTube 데이터 수집 자동화\n- ✅ **크론 스케줄**: 매일 새벽 6시 KST 자동 실행\n- ✅ **API 호출**: YouTube, Gemini, Supabase 연동\n- ✅ **에러 처리**: 실패 시 재시도 로직\n- ✅ **로그 기록**: 실행 이력 자동 저장\n\n### Slack 알림 자동화\n- ✅ **웹훅 트리거**: 백엔드에서 호출 시 즉시 실행\n- ✅ **스케줄 메시지**: Slack API로 예약 발송\n- ✅ **인터랙티브 버튼**: 시작/스누즈/완료 기능\n- ✅ **사용자별 개인화**: 맞춤 운동 추천\n\n## 🔧 실제 사용법\n\n### 워크플로우 테스트\n1. 각 워크플로우에서 **Test workflow** 버튼 클릭\n2. 실행 결과 및 에러 확인\n3. 각 노드별 입출력 데이터 확인\n\n### 실행 모니터링\n1. 왼쪽 메뉴에서 **Executions** 클릭\n2. 각 워크플로우의 실행 이력 확인\n3. 성공/실패 상태 및 실행 시간 분석\n\n### 디버깅 방법\n1. 실패한 실행을 클릭하여 상세 로그 확인\n2. 각 노드의 입출력 데이터 분석\n3. Error 메시지를 통한 문제점 파악\n\n## 🐛 문제 해결\n\n### 자주 발생하는 문제들\n\n**1. API 키 오류**\n```\n증상: \"Unauthorized\" 또는 \"Invalid API key\" 에러\n해결: \n- Settings → Variables에서 API 키 재확인\n- 키에 공백이나 특수문자가 없는지 확인\n- API 키의 권한 및 할당량 확인\n```\n\n**2. 웹훅 연결 실패**\n```\n증상: Slack 알림이 발송되지 6시)\n- 타임존 설정 확인: Asia/Seoul\n```\n\n**4. 노드 연결 에러**\n```\n증상: \"Node execution failed\" 에러\n해결:\n- 이전 노드의 출력 데이터 형식 확인\n- 필수 입력값이 누락되지 않았는지 확인\n- HTTP 노드의 경우 URL과 헤더 설정 재확인\n```\n\n## 💰 비용 최적화\n\n###
