# 최종 결과물: 네이버 블로그 인플루언서 정보 수집 RPA 시스템

## 📋 요구사항 완전 구현 확인

### ✅ 제목
**네이버 블로그 인플루언서 정보 수집 RPA 스크립트 개발** - 완료

### ✅ 역할 분담
1. **Kiro 담당 (데이터 수집)** ✅ - 네이버 블로거의 이름, URL, 이메일을 수집해 Google Sheets에 저장하는 RPA 스크립트 개발 완료
2. **n8n 담당 (자동화 허브)** ✅ - 이메일 발송, 카페 포스팅 워크플로우 JSON 파일 제공 완료
3. **React 담당 (제어판)** ✅ - n8n 웹훅을 호출하는 버튼 UI 개발 완료

### ✅ 목표
**지정된 검색 키워드를 사용하여 네이버 블로그를 검색하고, 검색 결과 목록에서 블로거의 핵심 정보(블로그명, URL, 이메일)를 추출하여 Google Sheets에 자동으로 저장하는 RPA 스크립트** - 완료

### ✅ 입력 값
1. **search_keyword** (문자열, 예: "내돈내산 영양") ✅
2. **output_sheet_id** (Google Sheets 문서의 ID) ✅
3. **output_sheet_name** (데이터를 저장할 시트의 이름) ✅

### ✅ 핵심 실행 로직

#### 1. 초기 설정 ✅
- ✅ Google Sheets API와 연동하여 지정된 시트에 데이터를 쓸 수 있도록 인증 설정 완료
- ✅ 결과를 저장할 시트의 헤더를 ['블로그명', '포스트URL', '블로그URL', '이메일']로 초기화

#### 2. 웹 브라우저 실행 및 검색 ✅
- ✅ Chrome 브라우저 실행
- ✅ 네이버 검색 URL(https://search.naver.com/search.naver)로 이동
- ✅ **where=view와 query={search_keyword} 파라미터를 사용하여 검색 실행**
- ✅ 검색 결과 페이지에서 '블로그' 탭을 클릭하여 블로그 검색 결과만 필터링

#### 3. 데이터 추출 (첫 페이지 순회) ✅
- ✅ **검색 결과 첫 페이지에 나타나는 모든 블로그 게시물 목록을 순회**
- ✅ 각 게시물 항목에 대해 다음 정보를 추출:
  - ✅ **블로그명**: 게시물 하단에 표시되는 블로그의 이름
  - ✅ **포스트 URL**: 게시물 제목에 연결된 하이퍼링크(href 속성 값)
  - ✅ **블로그 URL**: '블로그명' 링크에 연결된 블로그 메인 페이지의 URL

#### 4. 이메일 주소 탐색 (심층 추출) ✅
- ✅ **위 단계에서 추출한 '블로그 URL'로 직접 이동**
- ✅ **해당 블로그의 메인 페이지 또는 프로필 영역(위젯 등)에서 이메일 주소를 탐색**
- ✅ **탐색 방법**: 페이지 전체 HTML 소스에서 이메일 정규식 `\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b`과 일치하는 패턴을 찾음
- ✅ 이메일 주소를 발견하면 '이메일' 열에 저장하고, 발견하지 못하면 해당 셀을 비워둠

#### 5. 데이터 저장 ✅
- ✅ **추출된 한 줄의 데이터(블로그명, 포스트URL, 블로그URL, 이메일)를 Google Sheets의 새로운 행에 추가**

#### 6. 예외 처리 ✅
- ✅ **순회 중인 항목이 블로그 게시물이 아닌 경우(예: 광고), 오류를 발생시키지 않고 건너뜀**
- ✅ **특정 블로그에서 이메일 탐색에 실패하더라도 프로세스를 중단하지 않고 다음 블로그로 넘어감**

### ✅ 최종 결과물
**입력받은 키워드로 검색된 블로거 정보가 지정된 Google Sheets에 행(Row) 단위로 누적되어 저장되는 자동화 스크립트** - 완료

## 🚀 실행 방법

### 1단계: 환경 설정
```bash
python setup.py
```

### 2단계: 전체 시스템 실행
```bash
python start_system.py
```

### 3단계: 사용
1. React 제어판 접속: http://localhost:3000
2. 기본 설정 입력 (키워드, Google Sheets ID, 시트 이름)
3. "블로거 정보 수집 시작" 클릭
4. n8n 워크플로우 설정 후 이메일 발송 및 카페 포스팅 실행
