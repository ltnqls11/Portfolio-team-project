# 온라인 마케팅 연계 플랫폼 — 아이디어 설계(초안)

## 1) 제품 한 줄 정의 & 핵심 가치

### 한 줄 정의
"기업이 채널/인플루언서를 고르고, 맞춤형 홍보 문구를 자동 생성·배포·관리하는 올인원 플랫폼."

### 핵심 가치
1. **문구 자동화**: 제품/경쟁사/사례를 학습해 채널별 톤·SEO 구조로 문구 생성
2. **매칭·연계**: 카테고리·도달·참여율에 맞춰 나노/마이크로 인플루언서를 추천 및 연락 자동화
3. **운영 자동화**: n8n으로 수집→정제→생성→발송→로그→리포트까지 파이프라인화

## 2) 대상 사용자(Persona) & 대표 시나리오

### 기업 마케터(광고주)

#### 기능1. 인플루언서 연계 홍보 요청
카테고리 선택 → 제품(키워드) 작성, 홍보 요청 내용 입력 → 홍보 채널 선택 → 채널별 문구 생성 → 적합 인플루언서에게 일괄 요청/DM/메일 발송 → 성과 모니터링

#### 기능2. 자체 홍보 채널 문구 생성
홍보 채널 선택 → 채널 링크 등록 → 홍보 문구 제안 요청

### 대표 시나리오(End-to-End)
1. 광고주가 캠페인 생성 (목표/기간/핵심 키워드/참고링크 입력)
2. 플랫폼이 문구 후보 자동 생성(네이버 블로그/인스타 스토리/피드/릴스용 포맷)
3. 카테고리·도달·참여율·최근 업로드 등을 기반으로 인플루언서 풀 추천
4. 선택된 대상에게 메일/DM 자동 발송 + 응답/상태 추적
5. 납품 링크/스크린샷 수집 → 성과(노출/클릭/키워드 순위/댓글수) 리포트

## 3) 기능 범위(버전 구분)

### 캠페인 생성
제품정보, 목표, 예산, 채널(네이버/인스타), 키워드, 참고링크 업로드

### 문구 생성
채널별 톤&SEO 구조로 3개 안 자동 생성(금칙어·길이·해시태그 규칙 적용)

### 주요 채널
네이버 블로그, 블로그스팟, 티스토리, 카카오채널, 인스타그램

### 인플루언서 탐색
- 초기엔 공개 프로필 크롤링 요약본(네이버 블로그 순위)으로 시작
- 카테고리/팔로워 구간/평균 참여율/최근 활동일 필터

### 연락 자동화(1차)
- **메일**: SMTP 연동 또는 n8n 구글 메일 자동화
- **인스타**: n8n dm 자동화

### 성과 기초 리포트
발송/응답/수락/게시/링크 수집 상태, 기본 지표 수기 입력/반자동 수집

## 5) 정보 구조(데이터 모델 초안)

```sql
clients(id, name, industry, contact_email, …)
campaigns(id, client_id, title, objective, budget, start_at, end_at, channels[], keywords[], reference_urls[])
copy_variants(id, campaign_id, channel, tone, length, text, score, approved_bool)
creators(id, platform, handle, category, followers, engagement_rate, email, dm_url, active_at, notes)
outreach(id, campaign_id, creator_id, channel, method[email|dm], status[pending|sent|replied|accepted|rejected], last_event_at, message_template_id)
deliverables(id, campaign_id, creator_id, url, posted_at, metrics_json)
events(id, type, payload_json, created_at) ← 로그/감사 추적
```

## 6) 화면 설계(간단 와이어)

### 대시보드
로그인 및 회원가입, 진행중 캠페인, 오늘 해야 할 일(승인 대기 문구/보낸 제안/답장)

### 캠페인 생성
기본 정보, 키워드, 참고링크 업로드, 채널 선택, 홍보 선택(인플루언서, 자체, 둘 다)

### 문구 제안
3안 카드(채널별 규칙/길이 표시, 금칙어 체크), 승인/수정

### 인플루언서 탐색
필터(카테고리/블로그 링크) → 선택

### 연락 보내기
메일/DM 템플릿 미리보기, 변수 치환(제품명, 쿠폰 등)

### 리포트
발송/응답/게재/링크/기본 메트릭

## 7) 기술 스택 & 아키텍처(실행 현실성 중심)

### 크롤링/정제
Python(Requests/BS4) + Apify(브라우저 필요시), Pandas

### 자동화 오케스트레이션
n8n (크론/웹훅/HTTP/Function/Email 노드)

### 백엔드
FastAPI + PostgreSQL(ORM: SQLModel/SQLAlchemy)

### 프론트
React+Vite, 컴포넌트 라이브러리(예: shadcn/ui), 차트(Recharts/Plotly.js)

### 연락수단
- **메일**: SMTP 또는 트랜잭션 메일 API
- **인스타 DM**: 정책·API 제약이 커서 초기엔 반자동(템플릿 생성+수동 발송) → 이후 정식 API/파트너십 검토

### 로그/관찰성
이벤트 로그 테이블 + 간단한 대시보드

## 8) 정책/리스크 체크리스트(필수)

- 플랫폼별 이용약관/자동화 정책 준수(특히 인스타 DM 자동화)
- 스팸 방지: 일별 발송량 제한, 옵트아웃, 템플릿 다변화
- 개인정보/연락처 처리: 동의·보관기간·삭제 프로세스
- 저작권/표절 방지: 참고링크 학습 시 '직접 복제' 금지, 변환율·유사도 관리(임계값)
- 메트릭 신뢰성: 크롤링 오류/차단 대비 리트라이·프록시·샘플링

## 9) 학습 실험(가설→검증)

- 문구 톤/길이 vs 응답률/수락률: 짧고 직관적 톤이 더 높은가?
- 카테고리 매칭 점수 모델: 참여율·최근성 가중치가 수락률을 설명하는가?
- 참고링크 유사도 임계값: 유사도가 너무 높으면 표절 리스크↑, 너무 낮으면 전환율↓ → 최적 임계 탐색

## 10) 단계별 착수 계획

1. **스펙 확정**: 아래 빈칸 결정(카테고리 1순위, 채널 범위, 초기 지표)
2. **데이터 시드**: 크롤링/CSV로 인플루언서 100~300명 소량 DB 구축(필수 컬럼만)
3. **문구 생성 규칙표**: 채널별 길이·구성(제목/후킹/본문/해시태그/CTA) + 금칙어 리스트
4. **n8n 워크플로우 1개**: "캠페인 생성 → 문구 3안 생성 → 승인 대기"
5. **프론트 초안**: 캠페인 생성 폼 + 문구 카드 뷰(승인/수정/재생성)

## 11) 규칙 기반(템플릿) + 모델 프롬프트 예시(초안)

### 입력
제품 또는 서비스 한 줄 설명, 주요 효익, 타깃(연령/관심사), 키워드, 참고링크 or 파일, 텍스트 요약

### 출력

#### 네이버 블로그용
- 제목 30 ~ 40자
- 본문 1500자 ~ 3000자
- 소제목 H2 3개
- 핵심키워드 5회 내 반복
- CTA 1개

#### 인스타 피드
- 150 ~ 220자
- 해시태그 8 ~ 12개
- 이모지 1~3개
- CTA 1개

#### 카카오 채널
규정에 맞춤

### 금칙/체크
과장/의학효능 금지, 특정 표현 필터, 링크 포맷, 유사도 상
